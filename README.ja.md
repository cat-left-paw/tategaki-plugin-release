# Tategaki（縦書き編集プラグイン）

[English](https://github.com/cat-left-paw/tategaki-plugin-release/blob/main/README.md) | [日本語](https://github.com/cat-left-paw/tategaki-plugin-release/blob/main/README.ja.md)

このリポジトリは、**Obsidian 用 縦書き編集プラグイン**の配布/開発ページです。  
Obsidian 上で、文章を**縦書きで「見たまま」編集**できるようにします。

本プラグインは、Obsidian のコミュニティプラグインからインストールできます。

※ **執筆・参照モードは新方式**です。Obsidian の Markdown を直接編集するため、変換・同期はありません。
※ 1.4.0 で、TipTapベースの「互換モード」と、独自の更新確認を廃止しました。**新執筆モード（実験的）**を追加しました（下の「新執筆モード（実験的）について」）。

**通常は Obsidian のコミュニティプラグイン画面からインストールしてください。**

---

## インストール / ダウンロード

通常は、Obsidian の標準機能からインストールします。

1. Obsidian の `設定` を開きます。
2. `コミュニティプラグイン` を開きます。
3. `閲覧` から `Tategaki` を検索します。
4. `Tategaki` をインストールして有効化します。

手動インストールや旧版からの移行が必要な場合は、[INSTALL.md](https://github.com/cat-left-paw/tategaki-plugin-release/blob/main/INSTALL.md) を参照してください。

## 移行メモ（ID変更）

`1.2.2` から、申請要件対応のためプラグインIDを `tategaki-plugin` から `tategaki` に変更しました。

旧版から更新する場合、Obsidian上で別プラグインとして扱われることがあります。必要に応じて次を実施してください。

- 旧プラグイン `tategaki-plugin` を無効化
- 新プラグイン `tategaki` をインストール/有効化
- 必要であれば設定を手動コピー
    - `.obsidian/plugins/tategaki-plugin/data.json`
    - `.obsidian/plugins/tategaki/data.json`
- プラグインコマンドのホットキーを再確認
- 動作確認後、旧フォルダ `tategaki-plugin` を削除

## レビュワー向け開示事項

- **対応環境**: デスクトップのみ（Windows / macOS / Linux）。モバイルは非対応です。
- **テレメトリ**: テレメトリ・分析データの送信は一切ありません。
- **ネットワーク通信**: プラグイン自身は通信しません。外部のページ（リリース・サポートのリンク）は、ユーザーがリンクを押したときだけ、Obsidian の機能で開きます。更新の確認はしません（更新は Obsidian のコミュニティプラグインの仕組みで行います）。
- **Vault 内ファイル一覧**: ファイル切り替え、執筆・参照モードのペア表示、新規ノート作成のために Markdown ファイル一覧を参照します。
- **Vault 読み書き**: 編集/閲覧対象ファイルの読み込み、執筆・参照モードでの保存、新規ノート作成のために Vault の読み書きを行います。実験的な新執筆モードは、開いたノートへ、そのノートの Obsidian の編集画面を通して書き込みます。
- **クリップボード**: エディタ内またはコンテキストメニュー（新執筆モードの 3 つだけのメニューを含む）でユーザーが copy / cut / paste を実行したときに、クリップボードの読み書きを行います。
- **ローカル保存**: バックアップファイルは作成しません。（1.4.0 で廃止した互換モードは、同期バックアップを `<Vault設定フォルダ>/tategaki-sync-backups/` に書き込んでいました。プラグインは自動では消さず、残っているときだけ設定画面に出る項目を、利用者が押したときに、ゴミ箱へ移します。）

## できること（主な機能）

- **執筆・参照モード**
    - Obsidian の Markdown を直接編集（変換・同期なし）
    - 縦書きの「見たまま編集」（縦書き/横書きの切り替え）
    - ペアの Markdown ノートを開いておくと、編集内容を縦書きでリアルタイム参照
    - 段落単位の「ソーステキスト編集」（その場で Markdown を直接編集）
    - `Home` / `End` / `PageUp` / `PageDown` などのキーボード移動を縦書き操作に合わせて調整
    - Typewriter scroll
        - 入力中のキャレットを、画面内の追従位置付近へ保つよう自動スクロール
        - 追従位置と、スクロールを始める帯域幅を調整可能
        - 文書末尾側でも入力位置を保ちやすい scroll past end と組み合わせて利用可能
    - 視覚フォーカス機能
        - 編集中ブロックのハイライト
        - 現在行のハイライト
        - 非フォーカス段落 / ブロックの減光
        - Typewriter scroll と併用も、単独利用も可能
    - 執筆・参照モードの選択モード切り替え（クリック優先 / ドラッグ選択優先）
        - 新規インストール時の既定値は `クリック優先`
        - Typewriter scroll 使用中は、実効的に `クリック優先` として扱われます
    - ルビ（青空文庫形式の記法をサポート）
        - 例: `｜漢字《かんじ》`
    - 縦中横（TCY）
        - 明示TCY: `｟A｠` / `｟12｠` のように 1〜4 文字を明示指定可能
        - 自動TCY: 英数字列の最小桁数 / 最大桁数を設定可能（`!!` / `!?` / `??` も対応）
    - 画像の表示（標準 Markdown 画像、Obsidian の画像埋め込み）
    - 箇条書き・番号付きリストを、アウトライナー感覚で整理
        - 項目の上下移動、Tab / Shift+Tab でのネスト変更、番号付きリストの連番補正に対応
    - リスト・引用ブロックでの Enter / Shift+Enter に対応
        - `Enter` で継続入力や終了を自然に処理し、`Shift+Enter` で項目内改行や空行継続が可能
    - 水平線行にキャレットを置き、`Delete` / `Backspace` で削除可能
    - ツールバーの Typewriter メニューから、`Typewriter scroll` / 編集ブロックハイライト / 現在行ハイライト / 非フォーカス減光 をまとめて切り替え可能
    - ツールバーからフォント・余白などを手軽に調整
    - 見出しの折りたたみ、見出し（アウトライン）ジャンプ
    - Typewriter 系設定は、source mode / 全文プレーン表示 / 段落プレーン編集 中は一時的に無効化され、通常 SoT に戻ると保存済み設定へ復帰
- **書籍モード（閲覧）**
    - 実測ベースのページ分割とページめくりで、読書に特化した表示
    - フロントマターを本文から分離して、独立した表紙ページとして表示可能
    - 見出し前の改ページや、章扉ページの挿入に対応
    - ルビ表示に対応
    - 見出しアウトライン/見出しジャンプに対応
    - ページ遷移効果（フェード等）
- **新執筆モード（実験的・既定 OFF）**
    - Obsidian の編集画面と対になって動く、新しい方式の縦書き執筆モード
    - 基本的な入力・変換（IME）・選択・コピーと貼り付けは使えますが、実験的な機能で、まだできないことがあります
    - 設定で有効にする必要があります
- **共通**
    - テーマ機能（フォント/文字サイズ/行間/色などを自分好みに）

## 執筆・参照モードについて

執筆・参照モードは、Obsidian の Markdown を直接編集する新方式です。**変換・同期の処理が不要**なため、従来の同期リスクがありません。

- 執筆・参照モードでは同期バックアップは行いません（不要なため）
- ペアの Markdown ノートをアクティブにすると、ビューが参照表示として追従します
- 段落単位の「ソーステキスト編集」で、装飾表示のまま Markdown を直接直せます
- リストはアウトライナー感覚で上下移動やネスト変更ができ、番号付きリストの連番も追従します
- リスト・引用ブロックでは Enter / Shift+Enter の挙動を調整してあり、`Enter` で継続入力や終了を自然に処理し、`Shift+Enter` で項目内改行や空行継続ができます
- ツールバーや表示設定から、選択モード、IME表示補正、余白などを調整できます

## 新執筆モード（実験的）について

新執筆モードは、**元のノートの Obsidian の編集画面と対になって動く**、新しい方式の縦書き執筆モードです。基本的な入力・変換・選択・コピーと貼り付けは使えますが、**実験的な機能で、まだできないことがあります**。既定は OFF で、既定のモードは執筆・参照モードのままです（設定の `新執筆モード（実験的）` を ON にします）。

- 同じノートの Obsidian の編集画面と対応づけて動き（開いていなければ別のタブに開きます）、**書き込みはその編集画面を通して、開いたノートへ直接行います**。対応づけた編集画面を閉じたり、別のノートに変えたりすると、新執筆モードも閉じます
- **大事な原稿は、控えを取ってからお使いください**（ファイルの複製、Obsidian の「バージョン履歴」など）
- 使い方と「新執筆モードでまだできないこと」の全文は、[MANUAL.md](https://github.com/cat-left-paw/tategaki-plugin-release/blob/main/MANUAL.md) の「新執筆モード（実験的）」の節にあります

### 互換モード（廃止）

TipTap ベースの「互換モード」は 1.4.0 で廃止しました。互換モードで開いたままだったビューは、執筆・参照モードで開き直し、1 度だけ知らせます。互換モードが作っていた古い同期バックアップは、自動では消しません。残っているときだけ設定画面に出る「互換モードの古いバックアップをゴミ箱へ移す」で整理できます。

## 制限事項

### 執筆・参照モード

執筆・参照モードでは、Obsidian の Markdown を直接文字マッピングして表示するため、以下の制限があります。

- **ペアノート**：対（ペア）になる Obsidian のノートを開いておく必要があります
    - ペアのノートのタブにはアイコンが表示されます
    - ペアのノートを閉じると、縦書きビューも自動的に閉じられます
- `<font>` や `<ruby>` などの HTML タグは、そのままプレーンテキストとして表示されます
- マークダウン以外の、HTML タグを使った装飾は反映されません（青空文庫形式のルビは正常に表示されます）

### 新執筆モード（実験的）

実験的な機能で、まだできないことがあります。再変換、書式などのコマンド、画像やファイルの貼り付けなどは、まだ使えません。一覧は [MANUAL.md](https://github.com/cat-left-paw/tategaki-plugin-release/blob/main/MANUAL.md) の「新執筆モードでまだできないこと」を見てください。

## 開発者向けメモ

### デバッグログの有効化

`data.json` の `common.debugLogging` を `true` にすると、`debugLog` / `debugWarn` が有効になります（既定は `false`）。

- 例: `"common": { "debugLogging": true, ... }`
- 反映にはプラグインの再読み込み（または Obsidian 再起動）が必要です。
